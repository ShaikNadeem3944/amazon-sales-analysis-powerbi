# Amazon Sales Analysis — Power BI

An interactive sales analytics dashboard built using Microsoft Power BI to analyze sales performance, profitability, products, customers, and regional trends.

> **Note:** This project uses a synthetic dataset created for learning and portfolio purposes. It does not contain actual Amazon customer or transaction data.

## 📊 Dashboard

The Power BI dashboard includes:

- Executive Overview
- Sales Overview
- Product Analysis
- Customer Analysis
- Time Analysis
- Regional Analysis

## 📈 Key Metrics

- Total Sales
- Total Orders
- Total Customers
- Total Profit
- Profit %
- Product Performance
- Regional Sales
- Monthly Sales Trends

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Excel
- GitHub

## 🔧 Power BI Concepts Used

- Star Schema Data Model
- Fact and Dimension Tables
- Data Cleaning with Power Query
- DAX Measures
- KPI Cards
- Bar & Column Charts
- Line Charts
- Slicers
- Page Navigation
- Date Analysis
- Top-N Analysis
- Interactive Filtering
